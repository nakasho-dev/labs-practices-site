## この方法の使い方

### サンプルアジェンダとプロンプト

1. 物理的またはデジタル/オンラインホワイトボードに、同じサイズの3つの列を作成し、左から右に「アイデア」、「作業合意」、「アイスボックス」とラベルを付けます。

2. グループとして、一緒に働く方法を導く行動と基準のセットを共同作成し、次に合意することをチームに説明します。

   {{% callout %}}
   ヒント：チームにオープンマインドを保ち、全員が貢献し、人々を中断したり会話を支配したりしないようにするように依頼します。
   {{% /callout %}}

3. 付箋を書く前に、全員にチームで働くときに重要なことについて考える時間を取るように依頼します。これらをプライベートに書き留めるように促します。

   {{% callout %}}
   ヒント：チームに、素晴らしいチームで働いた時とそれらを素晴らしくしたもの、および挑戦的だったチームとそれらをより挑戦的でなくするために何が違っていたかを振り返るように促します。
   {{% /callout %}}

   {{% callout %}}
   ヒント：チームメンバーが多くのメモを取っていない場合、自分が観察したトピックを提案できます。たとえば：

   - 「コア作業時間に同意したことはありません。」
   - 「リモートスタンドアップ中、一部の人はカメラをオンにしていますが、他の人はオフにしています。どう思いますか？」
   - 「ミーティングをスケジュールする場当たり的な方法についてどう思いますか？」
     {{% /callout %}}

4. 次に、チームの各メンバーに、成功したチームを作成するのに役立つと信じる1つの合意を書き、「アイデア」列に追加するように依頼します。

   {{% callout %}}
   ヒント：チームが5人未満の場合は、全員に2つの合意を書いてもらうことをお勧めします
   {{% /callout %}}

   {{% callout %}}
   ヒント：誰でも使用できる例のリストを追加/呼び出して、チームが必要とする可能性のある見落とされた健全な価値のいくつかをカバーします。例：通話でカメラをオン、スタンドアップ中は電話を使用しない、タイムゾーン間の柔軟性。
   {{% /callout %}}

   {{% callout %}}
   ヒント：合意の数を出席者の数に対してチェックし、等しくなるまでグループにプロンプトすることで、参加を目指すことができます。
   {{% /callout %}}

5. グループとして合意を読み通し、類似の合意を単一の合意に結合します。

   {{% callout %}}
   ヒント：合意が高レベルで書かれ、細かい点ではなく価値に焦点を当てていることを確認してください。例：「常に午後12時EST に昼食を取る」は、「毎日昼食休憩を取るようにします」に変えることができます。
   {{% /callout %}}

6. 作業合意が次のトピックをカバーすることを強くお勧めします。これらがボードにない場合は、リードを取って追加します：

   - コア作業時間
   - ミーティングスケジュール
   - 休憩
   - 通話エチケット
   - フィードバックを与える方法と時期

7. 提案が具体的すぎるか、作業合意のエトスに無関係に感じられる場合は、「アイスボックス」列に移動します。

8. チームとして各合意を通過し、声に出して読み、次に合意にコミットするための投票を開始します。

   合意は全会一致の投票を受けた場合にのみ合意されます。全員が参加することを確認してください。「いいえ」票が発生した場合、投票を「はい」に変えるために何が必要かについて、チームメンバーに明確化を求めます。

   これに対応することが実行可能と思われる場合は、チームとして一緒にそれを実現するために何ができるかについて議論し、調和をもたらすために書かれた合意を調整します。

   合意に100%のイエス票を得ることが実行不可能な場合は、「アイスボックス」列に移動します。

9. すべての合意についてこれを行ったら - チームの最終投票を取って、合意の合計セットに合意します。繰り返しますが、これは続けるために全会一致の投票が必要です。これが不可能な場合は、前のステップに戻ります。

10. 最後に、合意を公開し、全員がアクセスできるようにします。

    {{% callout %}}
    ヒント：合意を全員にメールし、考えの燃料として週次のレトロスペースに追加します。
    {{% /callout %}}

    PDFの例を次に示します：[Team working agreement document example](images/team-working-agreement-example.pdf)

## 成功/期待される成果

チームの100%が投票して合意した明確な作業合意のセットがあるときに、このタスクを正常に完了しました。

## ファシリテーターのメモとヒント

これは、引きずられていると感じた場合に時間制限できる活動です。上に埋め込まれた多くのヒントは、ラビットホールを避けるのに役立つことを意図していますが、それが起こった場合は、チームを再焦点化し、タイマーを設定し、または決定を強制することで、物事を前進させる権限を感じるべきです。

また、行動が作業合意に追加されなかったからといって、チームメンバーがその方法で振る舞えない、または他の人にその方法で振る舞うように求めることができないわけではありません。まれに、合意をめぐって激しい意見の相違に陥った場合、チームにこれを思い出させる必要があるかもしれません。
