## この方法の使い方

### サンプルアジェンダとプロンプト

1. 物理的またはデジタル/オンラインホワイトボードに、同じサイズの3つの列を作成し、左から右に「Ideas」、「Working Agreements」、「Ice Box」とラベルを付けます。

2. グループとして、一緒に働く方法を導くための行動と基準のセットを共同作成し、同意することをチームに説明します。

   {{% callout %}}
   ヒント: チームにオープンマインドを保つように、全員が貢献するように、人々を中断したり会話を支配したりしないように依頼します。
   {{% /callout %}}

3. 付箋を書く前に、全員にチームで働くときに重要なことについて考える時間を取るように依頼します。これらをプライベートに書き留めるように促します。

   {{% callout %}}
   ヒント: 偉大なチームで働いた時と、何が彼らを偉大にしたか、および挑戦的だったチームと、何が違っていれば挑戦的でなくなったかについて、チームに反省するように促します。
   {{% /callout %}}

   {{% callout %}}
   ヒント: チームメンバーが多くのメモを取っていない場合は、自分が観察したかもしれないトピックを提案できます。例えば：

   - 「コア作業時間について同意したことがありません。」
   - 「リモートスタンドアップ中、カメラをオンにしている人もいれば、オフにしている人もいます。それについてどう思いますか？」
   - 「ミーティングをスケジュールする無計画な方法についてどう思いますか？」
     {{% /callout %}}

4. 次に、チームの各メンバーに、成功したチームを作成するのに役立つと信じる1つの合意を書き、「Ideas」列に追加するように依頼します。

   {{% callout %}}
   ヒント: チームが5人未満の場合は、全員に2つの合意を書いてもらうことをお勧めします
   {{% /callout %}}

   {{% callout %}}
   ヒント: チームが必要とする可能性のある見落とされがちな健全な価値をカバーする例のリストを追加/呼び出します。例：通話中のカメラ、スタンドアップ中の電話なし、タイムゾーン間の柔軟性。
   {{% /callout %}}

   {{% callout %}}
   ヒント: 合意の数を出席者の数と照合し、等しくなるまでグループにプロンプトすることで、参加を目指すことができます。
   {{% /callout %}}

5. グループとして合意を読み、類似の合意を1つの合意に結合します。

   {{% callout %}}
   ヒント: 合意が高レベルで書かれ、細部ではなく価値に焦点を当てていることを確認してください。例：「常に午後12時ESTに昼食を取る」は、「毎日昼食休憩を取るようにする」に変えることができます。
   {{% /callout %}}

6. 作業合意が次のトピックをカバーすることを強くお勧めします。これらがボードにない場合は、リードしてそれらを追加してください：

   - コア作業時間
   - ミーティングスケジュール
   - 休憩
   - 通話エチケット
   - フィードバックを提供するタイミングと方法

7. 提案が具体的すぎる、または作業合意のエトスに無関係であると感じる場合は、「Ice Box」列に移動します。

8. チームとして各合意を通過し、声に出して読んでから、合意にコミットするための投票を開始します。

   合意は、全会一致の投票を受けた場合にのみ同意されます。全員が参加することを確認してください。「いいえ」票が発生した場合は、チームメンバーに、投票を「はい」に変えるものについて明確にするように依頼します。

   これを受け入れることが実現可能に思える場合は、チームとして一緒に何ができるかを議論して、それを実現し、調和をもたらすために書かれた合意を調整します。

   合意に100%の賛成票を得ることが不可能な場合は、「Ice Box」列に移動します。

9. すべての合意についてこれを行ったら - 合意の合計セットに同意するためにチームの最終投票を行います。再び、これには継続するための全会一致の投票が必要です。これが不可能な場合は、前のステップに戻ります。

10. 最後に、合意を公に投稿し、全員がそれらにアクセスできることを確認します。

    {{% callout %}}
    ヒント: 合意を全員にメールで送信し、毎週のレトロスペースに思考の燃料として追加します。
    {{% /callout %}}

    PDFの例を示します：[Team working agreement document example](images/team-working-agreement-example.pdf)

## 成功/期待される成果

チームの100%が投票し、同意した明確な作業合意のセットがある場合、このタスクを正常に完了しました。

## ファシリテーターのメモとヒント

これは、長引いていると感じる場合に時間制限できる活動です。上記に埋め込まれた多くのヒントは、ウサギの穴を避けるのに役立つことを目的としていますが、それが起こった場合は、チームを再集中させる、タイマーを設定する、または決定を強制することで物事を前進させる力を与えられるべきです。

また、行動が作業合意に追加されなかったからといって、チームメンバーがその方法で行動できない、または他の人にその方法で行動するように依頼できないわけではありません。まれに、合意をめぐって激しい意見の相違に陥った場合、チームにこれを思い出させる必要がある場合があります。
