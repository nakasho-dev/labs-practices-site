## この方法の使い方

{{< callout >}}
**注意:** この技術は、アイデアと問題の優先順位付けと整列を得るために非常に効果的ですが、**_従業員のパフォーマンス_**のベストプラクティスとはもはや見なされていません。詳細については、これらの2つの記事を参照してください：

- [How stack ranking corrupts culture, at Uber and Beyond](https://www.perdoo.com/resources/stack-ranking/)
- [What Is 'Stack Ranking' and Why Is It a Problem \[for talent management\]? ](https://lattice.com/library/what-is-stack-ranking-and-why-is-it-a-problem)
  {{< /callout >}}

## サンプルアジェンダとプロンプト

1. 優先順位付けするすべてのオプションを収集し、それぞれを個別の付箋(またはデジタル同等物)に書きます。

2. これらのオプションを評価および優先順位付けする基準について一緒に決定します。

   {{< callout >}}
   **例**: ユーザーの喜び、技術的複雑さ、ビジネスドライバーへの影響など。
   {{< /callout >}}

3. 垂直線を作成し、選択した基準でラベルを付けます。

   {{< callout >}}
   **例**: 「より大きなユーザーの喜び」、「ビジネスドライバーへの影響が低い」
   {{< /callout >}}

   ![Vertical Axis with Blank Sticky Notes Ready](images/image1.png)

**ここから、この単一の軸に沿ってオプションを集合的に配置するときにチームディスカッションを促進する複数の技術があります。**

### バリエーション - [バブルソート](https://en.wikipedia.org/wiki/Bubble_sort)技術：10以下のオプション

4. ランダムにオプションを選択し、垂直線の中央の横に配置します。

   ![Vertical axis with one sticky note placed in the middle](images/image3.png)

5. ランダムに2番目のオプションを選択し、チームに尋ねます。「このオプションは、基準に従って最初のオプションよりも高いまたは低いべきですか？」チームの優先順位付けの決定に従って、2番目のオプションを最初のオプションの上または下に配置します。

   ![Decide to place the second note above or below the first note](images/image2.png)

6. ステップ4と5で行ったように、残りのオプションを他のアイテムと相対的に配置し続けます。すべてのオプションが線に対して垂直にスタックされるまで。

### バリエーション - トリアージ技術：10以上のオプション

4. グループとして、基準に基づいてオプションを3つのグループに分割します：最高、中程度、最低。グループを垂直軸に沿ってそれに応じて配置します。

5. 最高のスタックから始めて、より高い価値のアイテムを低い価値のアイテムの上に置いて、個々のアイテムを軸上に垂直に配置することを議論します。そのスタック内のすべてのアイテムを線に対して垂直に配置するよう努めます。

6. 残りのスタックで必要に応じて、または時間が許す限り続け、アクションを起こすのに十分なオプションが線に対して垂直にスタックされるまで。

### バリエーション - 個別ランキングとグループ比較：3〜9のオプションとグループに不均衡なパワーダイナミクスがある状況

4. グループ内の各個人がそれぞれのオプションと基準軸のコピーを作成します。

5. 全員が自分の基準軸に沿ってオプションを個別にランク付けするために5分間のタイマーを設定します。最も高く評価されたオプション(基準に従って)は、低く評価されたオプションの垂直上に配置されます。

6. 全員が自分のスタックランクを持っている場合、低パワーの個人に自分の最終結果を共有するように依頼することから始めます。そこから全員の結果を比較し、重要な相違点の背後にある理論的根拠を議論します。
   グループ内の全員がサポートできる最終的なスタックランクリストに向けて取り組みます。

## 成功/期待される成果

グループが降順に優先順位付けされたオプションのスタックを持ち、上位の優先順位付けされたオプションを特定できる場合、完了したことがわかります。

## ファシリテーターのメモとヒント

- 20以上のアイテムがある場合は、選択された基準に無関係なオプションを削除することに時間を費やすことを検討してください。
- すべての参加者が相互に理解していない場合、基準が何を意味するか(例：「ビジネスへの影響」とはどういう意味ですか？)を最初に議論して定義することが役立つ場合があります。これにより、優先順位付けがよりスムーズに進みます。
- コンセンサス(全員が優先順位に100%同意する)はめったに実現可能ではありません。目的は、焦点を当てるものについて整列を達成することです。
- このプラクティスは、2x2優先順位付けセッションの終わりに使用して、議論されたアイテムの右上象限を取り、アクションの順序に変換できます。
