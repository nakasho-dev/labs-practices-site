## この方法の使い方

{{% section %}}

### サンプルアジェンダとプロンプト

1. 物理的またはデジタルのホワイトボードに4つの列を作成し、それぞれに次のラベルを付けます：

   - User
   - Goal
   - Context
   - Scenario

   {{% callout %}}
   **ヒント**: 時間が短い、および/またはフルチームが他の作業で忙しい場合、選択したワードプロセッシングプログラムを使用して、自分/ペアでこの活動を行うこともできます
   {{% /callout %}}

1. **user**を定義することから始めます。理想的には、チームが作成したペルソナを使用します。書くものはこれらの質問に答える必要があります：

   - この人は誰ですか？
   - 彼らの役割は何ですか？

   {{% callout %}}
   **ヒント**: ペルソナが利用可能な場合、ゼロから作成するのではなく、このセクションでそれを使用できます
   {{% /callout %}}

   [Personas](/practices/personas/)活動を使用して、チームが適切に形成されたペルソナを作成するのを導くことができます

1. 次に、シナリオの**goal**を定義します。書くものはこれらの質問に答える必要があります：

   - ユーザーは何を達成しようとしていますか？
   - シナリオはいつ完了しますか？

1. 次に、シナリオの**context**を定義します。書くものはこれらの質問に答える必要があります：

   - このシーンはどこで行われていますか？
   - このシナリオが行われるとき、ユーザーは何をしていますか？
   - 使用されているデバイスは何ですか（もしあれば）？
   - ユーザーは誰といますか（もしいれば）？

1. 最後に、始めから終わりまで**scenario**を概説し、以下について必ず書きます：

   - 主要なアクションが始まる前にユーザーが行う関連すること
   - ユーザーが目標に到達するために取るアクションと、なぜそれらを取るか
   - シナリオの目標を達成した後にユーザーが行う関連すること

   {{% callout %}}
   **ヒント**: 将来の状態のシナリオを書いている場合は、ソリューションをキャプチャする際にあまり規範的にならないように注意してください。チームが広くアイデアを出すためのスペースを持つように、十分な曖昧さを残してください。
   {{% /callout %}}
   {{% /section %}}

{{% section %}}

### 成功/期待される成果

チームが現在または将来のシナリオの範囲を理解し、後続の活動（調査、デザインスタジオなど）をサポートするためにそれを自信を持って使用できると感じたら、成功しました
{{% /section %}}

{{% section %}}

### ファシリテーターのメモとヒント

**現在の状態**シナリオの例：  
羊農家が現在どのように対面でオークションで羊を購入しているか

**将来の状態**シナリオの例：  
羊農家が新製品でインターネット経由で羊を購入する方法
